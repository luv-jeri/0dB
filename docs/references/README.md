## How to use them

- Find the poster your component descends from (DESIGN.md "Where each move comes from" names it), open it, and ask: what makes this poster striking? Keep that. Legibility and accessibility are fixed with the poster's own means (scale, weight, knock-out, the accent), never by shrinking the idea until it's gone.
- A result that looks like any calendar, any pager, any link is a failure, even when every check passes.
