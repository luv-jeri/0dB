**Gaps:**

1. **Independent install evidence.** A green deployment gate currently cannot establish that one registry command produces a building consumer app. Address A18 first.
2. **Interaction and accessibility coverage.** `scripts/check-pages.mjs:38` checks page errors and overflow; its RTL and reduced-motion checks are limited to one overflow case and one token value. It does not exercise keyboard flows, focus restoration, forced colours or changing component data.
3. **Production performance evidence.** There is no enforced JS/CSS/font budget or loading-performance threshold. Final bundle weight and scroll-frame costs remain unverified.
4. **Consumer guidance.** Install paths and prop tables need reconciliation. Browser requirements should explicitly distinguish basic rendering from enhancements that depend on newer capabilities.

**What is good:**

- All **107 payloads / 211 installed targets** were checked for dependency closure. No missing actual local imports or npm dependencies were found; A4 is an extra dependency.
- Native controls, chart keyboard navigation, readable chart values, reduced-motion tokens and forced-colour styles show deliberate accessibility work.
- Permission prompts default focus to Deny and treat Escape as denial.
- Registry generation and contract/drift checks centralize useful consistency guarantees.
- Static export routing, promise-based Next params, the recovery-focused 404, baseline headers and immutable asset caching are sensibly configured.
- Fonts carry OFL notices. No obvious credentials surfaced in the limited configuration/token scan; repository history was not audited.
